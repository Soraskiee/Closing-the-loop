# Closing the Loop

A low-fidelity clickable prototype for a hostel maintenance request flow. It demonstrates resident reporting, request progress, staff updates, and resident confirmation after repair.

## Demo notice

This is a classroom prototype. It does not contact hostel staff, submit a real request, or save information to a service. Demo entries and selected photos stay in the current browser page and are not sent to a server.

## Run locally

Open `index.html` in a modern web browser. Keep `index.html`, `style.css`, and `script.js` together in this folder.
